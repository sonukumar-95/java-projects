# Java Projects

This repository contains my Java and Spring-based projects created during my Java Backend Developer learning journey.

## Projects

### 1. Spring Boot Book REST API
A RESTful API built using Spring Boot for managing books with CRUD operations.

**Features**
- Add book
- Get all books
- Get book by ID
- Update book
- Delete book
- Tested using Postman

**Tech Stack**
Java, Spring Boot, REST API, Maven, Postman

**Folder:** `bootrestbook`

---

### 2. Product CRUD App
A Spring MVC-based CRUD application for managing products.

**Features**
- Add product
- View products
- Update product
- Delete product

**Tech Stack**
Java, Spring MVC, Hibernate, MySQL, JSP, Maven

**Folder:** `productcrudapp`

---

### 3. Spring MVC Search App
A Spring MVC mini project that redirects user search queries to search engines.

**Features**
- Search using Google/YouTube/Bing
- Controller-based request handling
- RedirectView implementation

**Tech Stack**
Java, Spring MVC, JSP, Maven
